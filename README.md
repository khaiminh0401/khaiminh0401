## Featured project — FlowDesk

[FlowDesk](https://github.com/khaiminh0401/flowdesk) is my personal workspace/workflow management project, currently in development. Its implemented foundation includes a Java 21 / Spring Boot 3.5 API, an Angular 20 SPA, PostgreSQL 17 / Flyway, a lazy dashboard with typed API connectivity and failure handling, automated tests and CI.
